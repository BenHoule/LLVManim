llvmanim.ingest¶

The ingest layer is responsible for reading LLVM IR from disk and converting it into LLVManim’s typed data structures. It also provides I/O helpers for supplemental files (CFG edges, traces, analysis metadata) and parses Graphviz DOT layout files.

Public API:

from llvmanim.ingest import parse_ir_to_events, parse_module_to_events

llvmanim.ingest.display_lines¶

Builds display-ready IR source lines for the IR panel in rich and rich-ssa modes.

Build per-function display lines from raw LLVM IR text.

Provides build_display_lines which parses a raw .ll string into a dict[str, list[str]] mapping bare function names to cleaned, display-ready IR source lines. The cleaning removes debug metadata, attribute references, verbose type qualifiers, and intrinsic calls that add noise without insight.

The result is stored in ProgramEventStream.display_lines so the presentation layer can render IR source panels without re-reading the .ll file.

Parse raw LLVM IR text into per-function display-line lists.

llvmanim.ingest.trace_io.load_trace(path)[source]¶

Load a runtime path trace from a JSON file.

Schema:

{
  "version": 1,
  "source": "<path>",
  "entry_order": ["main::entry", "main::while.cond", ...],
  "visited_nodes": ["main::entry", "main::while.cond", ...],
  "traversed_edges": [["main::entry", "main::while.cond"], ...],
  "termination_reason": "ret"
}

entry_order is required (the ordered sequence of block visits). visited_nodes and traversed_edges are optional — when absent they are derived from entry_order.

path (str | Path)

Load per-block analysis metadata from a JSON file.

Returns a mapping of block id ("func::block") to metadata.

Schema:

{
  "version": 1,
  "source": "<path>",
  "functions": [
    {
      "name": "main",
      "blocks": [
        {
          "id": "main::entry",
          "idom": null,
          "dom_depth": 0,
          "is_loop_header": false,
          "loop_depth": 0,
          "loop_id": null,
          "is_backedge_target": false
        }
      ]
    }
  ]
}

All per-block fields except id are optional; missing fields use defaults. The functions list may contain domtree-only or loop-only entries.

llvmanim.ingest.dot_layout¶

Parses a Graphviz DOT file (produced by opt -passes=dot-cfg) and returns a DotLayout with node positions, dimensions, and edge spline control points.

Parse Graphviz DOT layout into structured geometry for CFG visualization.

This module wraps dot -Tjson0 to compute node positions, dimensions, and edge spline control points from a .dot file produced by LLVM’s opt -passes=dot-cfg.

The output is a pure-data DotLayout structure that the presentation layer can map to Manim world coordinates.
