llvmanim.transform¶

The transform layer converts a flat ProgramEventStream from the ingest layer into a structured SceneGraph with an ordered animation timeline.

llvmanim.transform (package)¶

Transformation layer from IR events to scene plans.

llvmanim.transform.scene¶

Scene graph construction: groups IR events into blocks, assigns roles, builds edges, and generates the animation command timeline.

Scene graph construction from IR event streams.

llvmanim.transform.scene.build_scene_graph(event_stream, *, mode='cfg', analysis_metadata=None, entry='main', max_depth=20, include_ssa=False)[source]¶

Construct a scene graph from a stream of IREvents.

Pass mode="stack" to build a stack-frame visualization instead of a CFG graph. The entry, max_depth, and include_ssa keyword arguments are forwarded to the stack builder and ignored when mode="cfg".

Edges are taken from event_stream.cfg_edges, which the ingest layer populates for all terminator types via llvmlite.

When a TraceOverlay is later attached (via graph.overlay = ...), callers can run _build_overlay_commands(graph) to populate the commands list; build_scene_graph itself leaves commands empty because the overlay is typically loaded separately.

Parameters:

  • event_stream (ProgramEventStream)

  • mode (Literal['cfg', 'stack'])

  • analysis_metadata (dict[str, BlockMetadata] | None)

  • entry (str)

  • max_depth (int)

  • include_ssa (bool)

Return type:

SceneGraph

llvmanim.transform.trace¶

Static CFG-trace derivation: walks the graph from the entry block, always taking the true branch, and returns a TraceOverlay.

CFG-trace derivation: builds a static traversal path from a scene graph.

llvmanim.transform.trace.derive_cfg_trace(graph, function='main', *, max_loop_iterations=7)[source]¶

Derive a static CFG trace by walking edges from the entry block.

Branches with a “T” (true) label are taken first; the walk terminates at a block with no outgoing edges or when a loop back-edge has been followed max_loop_iterations times.

Returns a fully populated TraceOverlay.

Parameters:

  • graph (SceneGraph)

  • function (str)

  • max_loop_iterations (int)

Return type:

TraceOverlay
